The Reverse Process & the Simplified Loss

From intractable posteriors to six lines of training code. The mathematical journey that makes diffusion models work.

We know how to destroy images. Now comes the hard part: reversing that destruction. We'll work through the full derivation — from an intractable posterior, through the ELBO, to the result that training a diffusion model reduces to predicting noise. 3.1 The Reverse Process — What We Need

We know how to destroy images (Lecture 2). Now comes the real question: how do we generate new ones?

The plan is simple in concept. Start with pure noise $x_T \sim \mathcal{N}(0, I)$ and iteratively denoise, one step at a time: $x_T \to x_{T-1} \to \cdots \to x_1 \to x_0$. Each step reverses one forward noising step, gradually transforming random static into a clean image.

To do this, we need a model that defines the reverse step:

$$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}\!\left(x_{t-1};\; \mu_\theta(x_t, t),\; \sigma_t^2\, I\right)$$

The model takes a noisy image $x_t$ and a timestep $t$, and outputs the parameters of a Gaussian distribution over the slightly-less-noisy image $x_{t-1}$. In practice, the model predicts the mean $\mu_\theta$, and we fix the variance $\sigma_t^2$ to a known schedule (following DDPM).

There's a deep result by Feller (1949) that justifies this: when the forward steps are small enough (small $\beta_t$), the reverse steps are also approximately Gaussian. Our Gaussian parameterization is therefore not only convenient but also theoretically grounded.

3.2 Why the True Reverse Is Intractable

But there's a problem. The true reverse distribution $q(x_{t-1} \mid x_t)$ requires marginalizing over all possible clean images:

$$q(x_{t-1} \mid x_t) = \int q(x_{t-1} \mid x_t, x_0)\, q(x_0 \mid x_t)\, dx_0$$

Think about what this means. Given a noisy image $x_t$, the true reverse step considers every possible clean image $x_0$ that could have produced it, weights each by its likelihood $q(x_0 \mid x_t)$, and averages the resulting denoising steps.

But $q(x_0 \mid x_t)$ depends on the data distribution, the very thing we're trying to learn.

This is intractable. We can't compute this integral analytically or even approximate it directly. That's why we need a neural network: we'll train $p_\theta(x_{t-1} \mid x_t)$ to approximate $q(x_{t-1} \mid x_t)$ from data.

Key Insight

The intractability comes from $q(x_0 \mid x_t)$: the probability that some particular clean image $x_0$ was the original source of our current noisy image $x_t$. There are infinitely many clean images that could have produced any given noisy observation, and we'd need to consider all of them.

But if we did know which $x_0$ produced $x_t$, the reverse step becomes tractable. This observation is the foundation of the entire derivation.

3.3 The Tractable Posterior — q(xt−1 | xt, x0)

There is a tractable alternative. If we condition on both $x_t$ and $x_0$, the noisy image and the clean original, the posterior becomes tractable. Using Bayes' rule:

$$q(x_{t-1} \mid x_t, x_0) \propto q(x_t \mid x_{t-1}) \cdot q(x_{t-1} \mid x_0)$$

Both terms on the right are Gaussians that we know from the forward process. The product of two Gaussians is another Gaussian, so we can compute the result in closed form.

After working through the algebra (completing the square on the Gaussian exponents), we get:

Tractable Posterior

$q(x_{t-1} \mid x_t, x_0) = \mathcal{N}(x_{t-1};\; \tilde{\mu}_t,\; \tilde{\beta}_t\, I)$ where:

Posterior mean:

$$\tilde{\mu}_t = \frac{\sqrt{\bar{\alpha}_{t-1}}\, \beta_t}{1 - \bar{\alpha}_t}\, x_0 + \frac{\sqrt{\alpha_t}\, (1 - \bar{\alpha}_{t-1})}{1 - \bar{\alpha}_t}\, x_t$$

Posterior variance:

$$\tilde{\beta}_t = \frac{1 - \bar{\alpha}_{t-1}}{1 - \bar{\alpha}_t} \cdot \beta_t$$

Look at the posterior mean carefully. It's a weighted average of $x_0$ and $x_t$. The model's best guess for $x_{t-1}$ lies somewhere between the clean image and the noisy image. The weights depend on the schedule: at very early timesteps ($t \approx 1$), $x_0$ dominates because $x_{t-1}$ is nearly identical to the clean image. As $t$ grows, the balance shifts sharply toward $x_t$, since $x_{t-1}$ is now much closer to the current noisy state than to $x_0$.

The variance $\tilde{\beta}_t$ is small; the posterior is a tight Gaussian. This makes sense: knowing both the clean and noisy images pins down the intermediate state precisely.

But we don't have $x_0$ at test time. That's the whole point: we're trying to generate $x_0$.

So why is this useful? Because it tells us what the model should aim for. If the model can estimate $x_0$ from $x_t$, it can compute this posterior and take the reverse step. The ELBO derivation makes this precise.

3.4 The ELBO Derivation

The tractable posterior $q(x_{t-1} \mid x_t, x_0)$ gives us a training target: we know what the ideal reverse step looks like when $x_0$ is available. Since we have $x_0$ during training (it's our clean image from the training data), we can use it. The ELBO (Evidence Lower BOund) formalizes this into a tractable training objective.

Expand full ELBO derivation

Step 1: Start with log-likelihood

We want to maximize $\log p_\theta(x_0)$, the probability the model assigns to real training images. We can't compute this directly because it requires marginalizing over all latent variables $x_1, \ldots, x_T$.

Step 2: Introduce the forward process as a variational bound

Using Jensen's inequality with the forward process $q(x_{1:T} \mid x_0)$ as the variational distribution:

$$\log p_\theta(x_0) \geq \mathbb{E}_q\!\left[\log \frac{p_\theta(x_{0:T})}{q(x_{1:T} \mid x_0)}\right]$$

This is the ELBO, a lower bound on the log-likelihood that we can optimize.

Step 3: Decompose into per-timestep KL terms

The ELBO can be rewritten as a sum of terms, one per timestep:

$$\mathcal{L} = \underbrace{D_\text{KL}(q(x_T \mid x_0) \,\|\, p(x_T))}_{L_T} + \sum_{t=2}^{T} \underbrace{D_\text{KL}(q(x_{t-1} \mid x_t, x_0) \,\|\, p_\theta(x_{t-1} \mid x_t))}_{L_{t-1}} - \underbrace{\log p_\theta(x_0 \mid x_1)}_{L_0}$$

The $L_T$ term is a constant (no learnable parameters). The $L_0$ term is the final reconstruction step. The interesting terms are $L_1, \ldots, L_{T-1}$: each one measures how well the learned reverse step $p_\theta$ matches the true posterior $q$ at that timestep.

Step 4: KL between two Gaussians has a closed form

Both $q(x_{t-1} \mid x_t, x_0)$ and $p_\theta(x_{t-1} \mid x_t)$ are Gaussian. The KL divergence between two Gaussians with the same (fixed) variance reduces to the squared difference of their means:

$$L_{t-1} = \frac{1}{2\sigma_t^2} \left\| \tilde{\mu}_t(x_t, x_0) - \mu_\theta(x_t, t) \right\|^2$$

Step 5: The loss is about matching means

Training the model means making $\mu_\theta(x_t, t)$ as close as possible to $\tilde{\mu}_t(x_t, x_0)$ at every timestep. The model sees the noisy image $x_t$ and must predict the posterior mean, the optimal denoising direction.

The takeaway: the ELBO tells us to make the learned reverse step match the true posterior at every timestep. When both are Gaussian with fixed variance, this reduces to matching their means. The training objective is a sum of mean-squared errors, one per timestep.

3.5 The ε-Prediction Reparameterization

We could train the model to predict $\tilde{\mu}_t$ directly. But Ho et al. (2020) found a much better parameterization: instead of predicting the mean, predict the noise $\varepsilon$ that was added.

Recall from Lecture 2 that $x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \varepsilon$. We can rearrange this to express $x_0$ in terms of $x_t$ and $\varepsilon$:

$$x_0 = \frac{x_t - \sqrt{1 - \bar{\alpha}_t}\, \varepsilon}{\sqrt{\bar{\alpha}_t}}$$

Now substitute this into the posterior mean formula. After simplification, the posterior mean becomes a function of $x_t$, $t$, and $\varepsilon$:

$$\tilde{\mu}_t = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1 - \bar{\alpha}_t}}\, \varepsilon\right)$$

This suggests a natural parameterization: instead of predicting $\mu_\theta$ directly, have the network predict $\varepsilon_\theta(x_t, t)$, the noise that was added, and compute the mean from it:

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1 - \bar{\alpha}_t}}\, \varepsilon_\theta(x_t, t)\right)$$

Substituting into the MSE loss, the training objective becomes:

Core Result
$$L = \mathbb{E}_{t, x_0, \varepsilon}\!\left[\left\| \varepsilon - \varepsilon_\theta(x_t, t) \right\|^2\right]$$

Sample noise. Add it to an image. Ask the model to predict that noise. Minimize MSE.

Notice something subtle: the $\varepsilon$ in this loss is the total noise that takes $x_0$ all the way to $x_t$ in one shot via the closed-form shortcut from Lecture 2. It is not the small marginal noise from a single step $t{-}1 \to t$. Although we've been framing the reverse process as undoing one step at a time, the training target is the cumulative noise, because recovering $\varepsilon$ is equivalent to recovering $x_0$ itself, and knowing $x_0$ is all the model needs to compute the correct reverse step at any timestep.

Why does predicting noise work better than predicting the mean $\mu$ directly?

Consider what the network's target looks like in each case.

With $\mu$-prediction, the target changes dramatically across timesteps. At low $t$ (clean images), $\tilde{\mu}_t$ is close to $x_0$, a high-magnitude, highly structured signal. At high $t$ (pure noise), $\tilde{\mu}_t$ is close to zero, a tiny, unstructured target. The network must learn fundamentally different behaviors depending on the noise level, and the gradient signal at high-noise timesteps is vanishingly small.

With $\varepsilon$-prediction, the target is always a sample from $\mathcal{N}(0, I)$, regardless of timestep. The scale and distribution of the target stay constant. What changes is how much information $x_t$ gives the network to work with. This makes the learning problem more balanced across all noise levels.

This noise-prediction loss is almost the final training objective, but the ELBO still prescribes specific weights for each timestep. One more simplification remains.

3.6 The Simplified Loss (Lsimple)

The full ELBO loss has timestep-dependent weights in front of each $L_t$ term (related to $1/\text{SNR}(t)$). These weights emphasize high-noise timesteps where the KL divergence is largest.

Ho et al. made a surprising empirical finding: dropping these weights and using uniform weighting works better. The simplified loss is:

$$L_\text{simple} = \mathbb{E}_{t, x_0, \varepsilon}\!\left[\left\| \varepsilon - \htmlData{tip=The neural network (with weights θ) predicting the noise ε from the noisy image}{\varepsilon_\theta\!\left(\sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \varepsilon,\; t\right)} \right\|^2\right]$$

where $t$ is sampled uniformly from $\{1, \ldots, T\}$.

Why does uniform weighting help? The ELBO weights upweight high-noise timesteps (large $t$), where the model is essentially predicting noise from noise, which is not very useful for sample quality. Uniform weighting gives more training signal to the perceptually important mid-range timesteps, where the model learns the structure that matters most for sharp, realistic outputs.

Key Insight

Although $L_\text{simple}$ isn't the theoretically optimal ELBO loss, it's nonetheless a practical modification that produces better samples. This is a common pattern in deep learning: the "correct" objective isn't always the best one. Diffusion research continues to explore better loss weightings, including min-SNR weighting and progressive noise level emphasis.

3.7 DDPM Algorithm 1 — The Training Procedure

Everything we've derived collapses into a six-line training procedure: sample an image, pick a random timestep, add noise, predict that noise, compute MSE, take a gradient step.

Algorithm 1: Training (DDPM)
  1. repeat until converged:
  2. $x_0 \sim \text{dataset}$ // sample a training image
  3. $t \sim \text{Uniform}(\{1, \ldots, T\})$ // random timestep
  4. $\varepsilon \sim \mathcal{N}(0, I)$ // sample noise
  5. $x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \varepsilon$ // noise the image
  6. $\text{loss} = \left\| \varepsilon - \varepsilon_\theta(x_t, t) \right\|^2$ // predict noise, MSE loss
  7. Take gradient step on loss // update the network

Six lines. That's the entire training procedure behind Stable Diffusion 1.5. The same core idea, with variations in the prediction target (v-prediction, $x_0$-prediction) and framework (flow matching), underlies everything since, including DALL-E 2, Stable Diffusion 3, and Sora.

Let's walk through each line:

  • Line 2: Sample a batch of images from the training set.
  • Line 3: Pick a random timestep for each image. The model must handle all noise levels.
  • Line 4: Sample fresh Gaussian noise. This is both the corruption we'll apply and the target we'll predict.
  • Line 5: Apply the closed-form forward process (from Lecture 2) to get $x_t$ in one shot.
  • Line 6: Feed $x_t$ and $t$ into the neural network. Compare its output to the true noise $\varepsilon$. MSE loss.
  • Line 7: Standard gradient descent.

The simplicity is remarkable, and it all follows from the math. The ELBO decomposition, the Gaussian posterior, the $\varepsilon$-reparameterization, and the uniform weighting simplification all conspire to produce this clean training loop.

def train_step(model, x_0, schedule):
    # The entire DDPM training step
    t = random_integers(0, T, batch_size)               # random timesteps
    noise = sample_gaussian(x_0.shape)                  # ε ~ N(0, I)
    x_t = sqrt(schedule.alpha_bar[t]) * x_0
        + sqrt(1 - schedule.alpha_bar[t]) * noise      # forward process
    noise_pred = model(x_t, t)                         # predict the noise
    loss = mean_squared_error(noise, noise_pred)        # L_simple
    return loss

3.8 Alternative Parameterizations (Preview)

Although we've focused on the prevailing $\varepsilon$-prediction parameterization, it's not the only option. Three parameterizations are common in practice, and they're all mathematically equivalent; you can convert between them given $(x_t, t)$.

ε-prediction

Predict the noise $\varepsilon$ that was added. This is the DDPM standard and our focus in this lecture. It works well across most settings and is conceptually clean: the model is a denoiser.

x0-prediction

Predict the clean image $x_0$ directly. This can be better for low-noise timesteps (where the image is mostly intact and predicting it directly is natural), but struggles at high-noise timesteps where the model must hallucinate the entire image from almost no signal.

v-prediction

Predict the "velocity" $v = \sqrt{\bar{\alpha}_t}\, \varepsilon - \sqrt{1 - \bar{\alpha}_t}\, x_0$. This interpolates between noise prediction and image prediction, and is numerically stable across all timesteps, with target magnitude stays roughly constant regardless of $t$. Used in Stable Diffusion 2.0+ and many modern models.

Looking Ahead

We'll revisit these parameterizations in detail in Lecture 11, where we compare their training dynamics, loss landscapes, and empirical performance. For now, the important thing is that $\varepsilon$-prediction is the foundation. Understand it well, and the alternatives are straightforward variations.

PyTorch Reference

Here's a complete training step in PyTorch, grounding all the derivations in real code.

PyTorch
import torch
import torch.nn.functional as F

def train_step(model, x_0, schedule, optimizer):
    """One training step of DDPM (Algorithm 1)."""
    B = x_0.shape[0]
    device = x_0.device

    # Sample random timesteps
    t = torch.randint(0, schedule['T'], (B,), device=device)

    # Sample noise ε ~ N(0, I)
    noise = torch.randn_like(x_0)                     # (B, C, H, W)

    # Forward process: noise x_0 to timestep t
    sqrt_ab = schedule['sqrt_alphas_cumprod'][t]   # (B,)
    sqrt_om = schedule['sqrt_one_minus_ac'][t]    # (B,)
    while sqrt_ab.dim() < x_0.dim():
        sqrt_ab = sqrt_ab.unsqueeze(-1)
        sqrt_om = sqrt_om.unsqueeze(-1)
    x_t = sqrt_ab * x_0 + sqrt_om * noise         # (B, C, H, W)

    # Predict noise and compute loss
    noise_pred = model(x_t, t)                     # (B, C, H, W)
    loss = F.mse_loss(noise, noise_pred)

    # Gradient step
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    return loss.item()

3.9 Looking Ahead

The mathematical foundation is now complete: the forward process from Lecture 2 and the reverse process with its simplified training objective from this lecture. What's missing is the function approximator itself. The $\varepsilon$-prediction formulation calls for a network that takes a noisy image and a timestep and returns a noise tensor of the same shape, but says nothing about what architecture makes that prediction accurate.

The next lecture builds that architecture: the U-Net, the encoder-decoder with skip connections that has become the default denoiser in diffusion models. Since denoising requires preserving fine spatial detail while also reasoning globally about image content, the U-shape turns out to be a remarkably good fit. The skip connections carry high-frequency detail across the bottleneck, while the contracting path builds up the semantic context needed to decide what to denoise toward.
