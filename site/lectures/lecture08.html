Lecture 8

Conditioning & Classifier Guidance

Moving from unconditional to conditional generation — embedding class labels into the U-Net, then steering generation with a trained classifier's gradients.

Conditional Generation Class Embedding Classifier Guidance Historical Context

So far our model generates random images with no user control. To make it useful, we need conditioning — the ability to say "generate a 7." We'll embed class labels into the U-Net, then discover a more powerful idea: steering generation at sampling time using gradients from a trained classifier, trading diversity for fidelity with a single guidance scale parameter.

From Unconditional to Conditional Generation

Up to now, our diffusion model generates images — but we have no control over what it generates. We get random digits, random objects, random faces. For any practical application, we need to tell the model what to produce: "generate a 7" or "generate a cat."

The shift is surprisingly simple at the architectural level. Our unconditional model takes two inputs:

$$\epsilon_\theta(x_t, t)$$

A conditional model adds one more — a conditioning signal $c$:

$$\epsilon_\theta(x_t, t, c)$$

The condition $c$ can be almost anything: a class label (integer), a text prompt (sequence of embeddings), another image, even an audio clip. For this course, we'll focus on class-conditional generation with MNIST digits, where $c \in \{0, 1, \ldots, 9\}$.

Key Insight
The architecture change is minimal — we're adding one more input to the network. The interesting question is how that conditioning signal gets woven into the model's representations, and how we use it during sampling to steer generation.

Class Embedding & Injection

A class label is an integer — it carries no geometric or semantic structure. We need to lift it into a continuous vector that the network can work with. This is the same idea as word embeddings in NLP: map discrete tokens to learned vectors.

The Embedding Lookup

We create a learnable lookup table with one vector per class:

$$\texttt{class\_emb} = \texttt{nn.Embedding}(\texttt{num\_classes}, \texttt{emb\_dim})$$

Given a class label $c$, the embedding layer returns a vector of shape $(\texttt{emb\_dim},)$. This vector is randomly initialized and learned during training — the network discovers what each class "means" in embedding space.

Injection Method 1: Addition to Time Embedding

The simplest and most common approach: add the class embedding directly to the time embedding before the MLP. The network receives a single conditioning vector that encodes both when in the diffusion process we are and what class we're generating:

$$\texttt{combined\_emb} = \texttt{time\_emb}(t) + \texttt{class\_emb}(c)$$

This works well for class-conditional generation and is what we'll implement. Both embeddings have the same dimensionality, so the addition is element-wise.

Alternative Injection Methods

  • Separate injection: Process the class embedding through its own MLP, then add it to features at each ResBlock independently from the time embedding. More expressive, but more parameters.
  • Adaptive Group Normalization (AdaGN): Use the conditioning vector to predict per-channel scale and shift parameters for GroupNorm. This is the most expressive approach — used in DALL-E 2 and other advanced architectures.

The Null Class Token

One important detail: we allocate one extra class in our embedding table. If we have 10 digit classes (0–9), we create an embedding of size 11. Index 10 is the null class — it means "no conditioning." This will become critical in Lecture 9 when we implement classifier-free guidance, which requires the model to make predictions both with and without a class label.

Conditional U-Net Architecture class ConditionalUNet(UNet): def __init__(self, num_classes, ...): # +1 for null class token (index = num_classes) # "no class" enables unconditional prediction from same model self.class_emb = Embedding(num_classes + 1, emb_dim) def forward(self, x_t, t, class_label=None): t_emb = self.time_mlp(sinusoidal_embedding(t)) # (B, emb_dim) if class_label is not None: c_emb = self.class_emb(class_label) # (B, emb_dim) t_emb = t_emb + c_emb # combine # Rest of U-Net forward pass uses t_emb as before ...

Training the Conditional Model

The good news: training is nearly identical to what we did in Lecture 6. Each training sample now includes a label alongside the image: $(x_0, c)$. The label gets embedded and added to the time embedding. The loss function is unchanged:

$$\mathcal{L} = \|\epsilon - \epsilon_\theta(x_t, t, c)\|^2$$

The model learns to make class-specific noise predictions. When told "this is a 7 at noise level $t$," it predicts the noise differently than when told "this is a 3 at noise level $t$." The conditioning signal helps the model resolve ambiguity — at high noise levels, digits can look very similar, and the class label provides the extra information needed to denoise accurately.

Conditional Training Step def train_step(model, x_0, class_label, optimizer, schedule): t = random_integers(0, T-1, batch_size) noise = randn_like(x_0) x_t = q_sample(x_0, t, noise, schedule) noise_pred = model(x_t, t, class_label) # now with class! loss = mse_loss(noise_pred, noise) loss.backward() optimizer.step()
Example
Minimal change from unconditional training. Compare this to the unconditional training step from Lecture 6 — the only difference is passing class_label to the model. The loss, the noise sampling, the forward diffusion process: all identical. The architecture does the heavy lifting.

Classifier Guidance (Historical Context)

Now we have a model that accepts conditioning. But there's another question: can we make the conditioning stronger? Can we amplify how much the model pays attention to the class label during sampling? This is where guidance comes in.

The first approach, proposed by Dhariwal & Nichol (2021), was classifier guidance. It's an elegant idea that we'll study for historical context — it was superseded by the simpler classifier-free guidance in Lecture 9, but understanding it helps you appreciate why CFG was such a breakthrough.

Definition
Classifier Guidance. Train a separate classifier $p_\phi(y \mid x_t)$ on noisy images at all noise levels. During sampling, use its gradients to steer the denoising process toward the desired class.

How It Works

The idea is intuitive: at each denoising step, we ask a classifier "which direction should I move $x_t$ to make it look more like class $y$?" That direction is the gradient $\nabla_{x_t} \log p_\phi(y \mid x_t)$. We then shift our noise prediction in that direction.

Concretely, at each step of the reverse process:

  1. Predict noise as usual: $\epsilon_\theta(x_t, t)$
  2. Compute classifier gradient: $\nabla_{x_t} \log p_\phi(y \mid x_t)$ — "which direction makes $x_t$ look more like class $y$?"
  3. Shift the noise prediction: $$\hat{\epsilon} = \epsilon_\theta - s \cdot \sqrt{1 - \bar{\alpha}_t} \cdot \nabla_{x_t} \log p_\phi(y \mid x_t)$$
  4. Use $\hat{\epsilon}$ for the standard DDPM denoising step

The parameter $s$ is the guidance scale. It controls how strongly the classifier steers:

  • $s = 0$: no guidance — pure unconditional generation
  • $s = 1$: standard classifier guidance
  • $s > 1$: amplified guidance — sharper, more class-specific images, but less diversity

What Distribution Are We Sampling From?

Mathematically, classifier guidance causes us to sample from a sharpened distribution:

$$p_\text{guided}(x \mid y) \propto p(x) \cdot p(y \mid x)^s$$

When $s = 1$, this is just Bayes' rule — we get the standard conditional $p(x \mid y)$. When $s > 1$, we're raising the classifier likelihood to a power, which sharpens the distribution around images that the classifier confidently assigns to class $y$. Higher $s$ means sharper peaks but thinner tails — better fidelity, less diversity.

Sampling with Classifier Guidance

Classifier-Guided Sampling def classifier_guided_sample(model, classifier, class_label, schedule, s): x = randn(shape) # start from noise for t in reversed(range(T)): # 1. Standard noise prediction noise_pred = model(x, t) # 2. Classifier gradient x.requires_grad_(True) log_prob = classifier(x, t).log_softmax(dim=-1)[:, class_label] grad = autograd.grad(log_prob.sum(), x)[0] x.requires_grad_(False) # 3. Shift noise prediction toward desired class noise_pred = noise_pred - s * sqrt(1 - alpha_bar[t]) * grad # 4. Standard DDPM step with modified prediction x = ddpm_step(x, noise_pred, t, schedule) return x

Why Classifier Guidance Falls Short

Classifier guidance works — it produces sharp, class-specific images. But it has significant practical drawbacks:

  • Extra model required. You must train a separate classifier on noisy images at all noise levels. This classifier needs to handle everything from nearly-clean images ($t \approx 0$) to pure noise ($t \approx T$). That's an expensive, non-trivial training task.
  • Inflexible conditioning. Want to condition on text instead of class labels? You need to train an entirely new classifier. Each new conditioning modality requires a new external model.
  • Slow sampling. At every denoising step, you must compute gradients through the classifier via backpropagation. This is significantly slower than a simple forward pass.
  • Limited scalability. The approach doesn't naturally extend to rich conditioning signals like text prompts, which require understanding complex semantics rather than simple classification.
Key Insight
Classifier guidance proves that external signals can steer diffusion models during sampling. The problem isn't the idea — it's the execution. Training a separate model for each conditioning type is inelegant. What if the guidance signal could come from the diffusion model itself? That's exactly what classifier-free guidance achieves, and it's the subject of our next lecture.

PyTorch Reference

Here's how the conditional U-Net modification looks in real PyTorch. The key change from our unconditional model is just three lines: embedding initialization, embedding lookup, and the addition.

PyTorch import torch import torch.nn as nn class ConditionalUNet(nn.Module): def __init__(self, in_ch, out_ch, time_dim=256, num_classes=10): super().__init__() # ... existing U-Net layers ... # +1 for null class token used in CFG (Lecture 9) self.class_emb = nn.Embedding(num_classes + 1, time_dim) def forward(self, x, t, class_label=None): t_emb = self.time_mlp(self.sinusoidal_embedding(t)) # (B, time_dim) if class_label is not None: c_emb = self.class_emb(class_label) # (B, time_dim) t_emb = t_emb + c_emb # fuse conditioning # Forward pass uses t_emb exactly as before # Every ResBlock receives the same combined embedding ...

And the classifier guidance sampling loop in PyTorch:

PyTorch @torch.no_grad() def classifier_guided_sample(model, classifier, y, schedule, guidance_scale=3.0): x = torch.randn(batch_size, 1, 28, 28, device=device) for t in reversed(range(T)): t_batch = torch.full((batch_size,), t, device=device) # Noise prediction (no grad needed) noise_pred = model(x, t_batch) # Classifier gradient (grad needed for x only) with torch.enable_grad(): x_in = x.detach().requires_grad_(True) logits = classifier(x_in, t_batch) log_probs = logits.log_softmax(dim=-1) selected = log_probs[range(batch_size), y] grad = torch.autograd.grad(selected.sum(), x_in)[0] # Shift noise prediction alpha_bar_t = schedule['alphas_cumprod'][t] noise_pred = noise_pred - guidance_scale * (1 - alpha_bar_t).sqrt() * grad # Standard DDPM update step x = ddpm_step(x, noise_pred, t, schedule) return x
